
# 💰 Personal Budget Tracker

A beginner-friendly Python project that helps users track their monthly income and expenses efficiently.

## ✨ Features

- **Monthly Income Input** – Set your monthly income amount
- **Record Expenses** – Add multiple expenses with names and amounts
- **Total Expenses Calculation** – Automatically sums up all expenses
- **Remaining Budget** – Shows how much money is left after expenses
- **Overspending Warning** – Alerts if expenses exceed total income
- **CSV Export** – Saves all transaction data to a CSV file for record-keeping

## 🛠️ Technologies Used

- **Python 3.x**
- **File Handling** – Read/write operations
- **CSV Module** – Data storage and export

## 📁 Project Structure

```
Budget_Tracker/
├── budget_tracker.py   # Main program
├── expenses.csv        # Stored expense data

```

## 🔧 How to Run

1. Download or clone the project
2. Open terminal/command prompt in the project folder
3. Run the program:

```bash
python budget_tracker.py
```
